Add a text watermark to a PDF

Add a diagonal or horizontal text watermark with custom size, colour and opacity to every page.

How to: add watermark

  1. Add your PDF.
  2. Type the text and style it.
  3. Download the watermarked PDF.

About this add watermark tool

Mark documents as CONFIDENTIAL, DRAFT or with your name. Choose text, colour, size and opacity and apply it diagonally across every page.

Questions

Can I use any characters?

The built-in font supports Latin characters.

Can I change the watermark colour and opacity?

Yes – pick any colour and set how transparent the text should be.

Is it really free and private?

Yes. The tool runs entirely in your browser, so your files are never uploaded. A small optional tip (€1 plus 1 cent per processed page) is only a suggestion.

Does it work offline?

Yes. After the first visit the tools are cached by your browser and keep working without an internet connection.
