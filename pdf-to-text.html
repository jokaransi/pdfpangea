Extract text from a PDF

Copy out all text from a PDF as a plain .txt file – nothing leaves your device.

How to: pdf to text

  1. Add your PDF.
  2. Click “Extract text”.
  3. Download the .txt file.

Questions

Does it work on scans?

Only if the PDF contains real text. Scanned images need OCR, which is not included.

Is it really free and private?

Yes. The tool runs entirely in your browser, so your files are never uploaded. A small optional donation (1 cent per processed page) is only a suggestion.
