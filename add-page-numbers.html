Add page numbers to a PDF

Insert page numbers at any corner or centre, with formats like “Page 1 of 10” and a custom start number.

How to: page numbers

  1. Add your PDF.
  2. Choose position, format and start number.
  3. Download the numbered PDF.

Questions

Can I start from a number other than 1?

Yes, set “Start at”.

Is it really free and private?

Yes. The tool runs entirely in your browser, so your files are never uploaded. A small optional donation (1 cent per processed page) is only a suggestion.
